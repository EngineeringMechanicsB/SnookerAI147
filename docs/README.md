# Snooker · AI 147 开发文档

这套文档记录项目从原型到当前版本的设计、实现、调试和踩坑过程。不是 API
手册，也不是面向玩家的操作说明；目标是让后来维护的人知道**为什么这样写**，
以及改动某一层时会牵动什么。

项目本身仍然只有一个入口：双击根目录的 `index.html`。文档放在 `docs/` 内，
不影响离线运行。

## 项目一句话

一个完全离线的单页斯诺克/8 球/9 球游戏：原生 HTML/CSS/JavaScript，
three.js 做 3D，物理、规则、AI、教学、音频全部在本地运行，没有构建步骤，
没有音频文件，也没有后端。

## 文档约定

- 文中提到的“实机”指玩家实际出杆后的结算流程；“模拟”指 `sim.js` 用同一套
  物理跑一遍。两者共用 `stepWorld()`，这是整个项目可信度的基础。
- “AI”默认指 `js/ai.js` 的决策器；“加权层”指 `js/ai-style.js`。
- 代码路径相对于项目根目录。
- 文档写当前行为，不把历史方案当成现状；历史取舍放在第 10 章。

## 当前状态

- 斯诺克、8 球、9 球三种模式可玩。
- AI 档位：Novice、Amateur、Veteran、Master 147，以及五个真实球员画像。
- 教学：4 课 15 步；三点规划；犯规后的“重解”规则。
- 2D/3D 双视图；3D 台球厅场景；程序化音频。
- 3D 可点击酒杯/吊灯/花瓶；墙上排行榜；画质 Auto/Low/Medium/High。
- 浏览器自检 `index.html?selftest=1` 可用。
- 代码仓库：<https://github.com/EngineeringMechanicsB/SnookerAI147>

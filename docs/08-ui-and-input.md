# 08 UI 与交互

## 1. 布局原则

游戏画面在中间，HUD 在四周，控制条在底部。硬约束：

- 球台不能被 HUD 挤小；
- 状态行高度固定；
- 弹窗不能挡住关键球位；
- 2D/3D 切换不改变布局。

逻辑画布固定 `1416 × 736`，CSS 等比缩放。HUD 用绝对定位/网格布局覆盖在
画布上方，不参与画布尺寸计算。

## 2. 状态行

状态行固定 22px，显示：

- 当前球员；
- 当前该打什么球（Ball on）；
- 剩余球数；
- 比分；
- 临时提示。

教学和三点规划的面板也塞进这一行，而不是另起一行。早期它们各占一行，
一显示就把球台挤小；收进状态行后，球台尺寸稳定在 `1387 × 587`。

状态行的文字用固定宽度/预留空间，避免“剩 15 颗”到“剩 9 颗”时布局跳动。

## 3. 控制条

底部控制条包含：

- 力度条；
- 加塞盘；
- 俯仰环；
- 瞄准微调；
- 辅助线模式；
- 2D/3D 切换；
- 教学/规划按钮；
- 存档/读档/导出；
- 声音/暂停/重开。

控制条有 `z-index` 层叠上下文，菜单向上展开时稳定盖住画布，同时低于
结算弹窗。

## 4. 输入映射

| 操作 | 功能 |
|---|---|
| 移动鼠标 | 瞄准 |
| 点击台面 | 锁定/解锁瞄准 |
| 拖动力度条 | 设置力度 |
| `Space` / Shoot | 出杆 |
| 滚轮 / `Shift+←→` | 微调方向 |
| `A/D` 或 `←/→` | 调整方向 |
| `W/S` 或 `↑/↓` | 增加/减少力度 |
| `Shift + A/D` 或 `←/→` | 左/右侧塞 |
| `Shift + W/S` 或 `↑/↓` | 高杆/低杆 |
| `Q/E` | 左/右侧塞 |
| `X` | 清空加塞 |
| `G` | 切换辅助线 |
| `O` | 3D 轨道视角 |
| `P` | 暂停 |
| `H` / `Esc` | 隐藏/显示界面 |

输入处理分两套：

- 2D：鼠标位置直接映射到台面坐标，算瞄准角。
- 3D 俯视：用 `pickTable` 把屏幕坐标投到台面。
- 3D 轨道：鼠标拖动旋转相机，不直接改瞄准；点台面才改方向。

## 5. H 键：隐藏 UI + 网页全屏

`H` / `Esc` 不只是隐藏 HUD，还会对 `document.documentElement` 调
`requestFullscreen()`。再按一次 `exitFullscreen()` 并恢复 UI。

- 浏览器要求全屏必须由用户手势触发，`H` 的 keydown / 拉手点击满足条件；
- 如果用户用浏览器自带 `Esc` 退出全屏，`fullscreenchange` 会把 UI 恢复，
  不会留下一个没有任何控件的页面；
- 全屏切换后重新 `scheduleFit()`，画布按新视口等比适配。

## 6. 瞄准

`aimAt` 直接设置 `G.aimAngle = atan2(dy, dx)`，没有插值。早先用了 0.15 的
平滑，瞄准线会明显落后鼠标；去掉后跟手。

瞄准辅助线基于真实单杆模拟，支持：

- 关闭；
- 仅母球；
- 母球 + 首触；
- 全部球。

辅助线不是画一条直线，而是 `simulateShot(..., {track:true})` 的轨迹。

## 7. 加塞盘与俯仰环

加塞盘是圆形控件：

- 中心 = 无塞；
- 上下 = 高低杆；
- 左右 = 左右塞；
- 外环 = 俯仰角；
- 标出当前接触所需的最低仰角刻度。

后斯诺克场景下，外环会显示“最低抬杆角”，玩家可以继续抬高。
`fitContact()` 保证实际击点不会超出球面。

## 8. 全屏隐藏（视觉动画）

`H` / `Esc` 隐藏 UI，保留球台：

- 首次按下：UI 向下/向上滑出，带一点回弹；
- 650ms 后切到 `ui-hidden`；
- 再按：`ui-showing` 弹回；
- 屏幕上/下各留一个小拉手，点一下也能弹回；
- 人类回合、AI 回合、观战都能用。

早期只在观战模式支持，普通对局按 `H` 没反应；后来把处理移到正常输入路径。

动画用 cubic-bezier 的反冲曲线，模拟 Apple 风格的“拉出/弹回”。UI 隐藏后
画布仍接收鼠标，避免“看不见但点不到”。

## 9. 弹窗

项目里有几类弹窗：

- 暂停；
- 存档/读档；
- 教学课程菜单；
- 教学结果/教练笔记；
- 重解选择；
- 结算。

弹窗统一用 `hidden` 切换，不用 `display:none` 直接写死。`chatter-box` 在
`hidden` 时强制 `display:none !important`，避免聊天气泡关掉后还占位。

## 10. 球员对话

`chatter.js` 保存中英双语台词，按性格分组：

- 进球/失误/防守/被斯诺克/逆转；
- 有冷却时间，避免每杆都说话；
- 气泡有 watchdog，超过 6.5 秒强制隐藏；
- 观战时双方 AI 也会对话。

对话不是 LLM 生成，是规则触发的固定台词，保证离线。

## 11. 多语言

`i18n.js` 提供 `SNK.i18n`：

- 界面文字；
- 球名；
- 提示/错误；
- 中英文切换。

球员名保持英文，座位名用 `seatName()` 统一。教学和规划的文字也走 i18n，
但课程数据里的教练笔记是双语字段，按语言取。

## 12. 存档/读档

`save.js` 负责序列化：

- 球位、比分、当前玩家、模式；
- `needRed`、`pottedRedThisTurn`；
- `opening`、`negativeStreak`、`noPotStreak`；
- 教学进度；
- 当前视图/辅助线设置。

读档后：

- 不重新摆球；
- 不恢复 AI 思考状态；
- 回到“等待出杆”；
- 教学/规划状态清空，避免旧面板挂在正常对局上。

## 13. 移动/缩放

窗口缩放时：

- `canvas-fit` 重新计算 CSS 尺寸；
- 圆角和 `clip-path` 同步；
- 鼠标坐标按比例换算；
- 3D 相机视锥更新。

不做固定物理时间的累加器，所以缩放不会改变球速。

## 14. 3D 镜头与画质选项

- 3D 默认是正交俯视，不自动切透视。
- 右键/中键拖动进入透视轨道；`Shift+拖动` 平移；滚轮缩放。
- 进入 3D 后闲置 60~90 秒才自动缓慢环绕；鼠标操作打断。
- 画质下拉 `Quality: Auto/Low/Medium/High`，存 `localStorage` 的 `snk.gfx`。
- 画质只影响阴影/像素比/浮尘，不影响球桌和球的高精度几何。

## 15. 排行榜弹窗

- 时钟旁的黑板由 `render3d` 绘制，点击后调用 `openBoard()`。
- 人类赢局后，总结出现约 1.5 秒，弹出排行榜并提供
  `Record this score` / `Skip`；点 Record 才显示名字输入。
- 点 3D 黑板只查看，不显示记录按钮。
- 名字存 `localStorage` 的 `snk.playerName`，记录存 `snk.leaderboard.v1`。
- 排序：分数降序，同分用时升序；最多 10 条。
- `Esc` 关闭；输入框 `Enter` 保存。
- 榜单打开时暂停自动重开，避免名字还没输完就开下一局。

## 16. 中文/英文

- 球员名有 `name`/`nameZh`，`seatName()` 按语言取。
- AI 出杆理由通过 `tr()` 翻译常见句式和球名。
- 画质/氛围/速度/模式/辅助线选项在 `applyLanguage()` 里重写。
- 排行榜标题、表头、占位符走 i18n。
- 英文模式所有 UI 保持英文，中文模式全部中文。

## 17. 布局回归检查

改 UI 后至少检查：

1. 普通对局、教学模式、规划模式三种状态球台尺寸一致；
2. 状态行高度不变；
3. 全屏隐藏/弹回不遮挡画布输入；
4. 控制条菜单不被画布盖住；
5. 中英文切换不撑破按钮；
6. 3D 轨道下 HUD 仍在正确位置。

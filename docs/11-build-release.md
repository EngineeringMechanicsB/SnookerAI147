# 11 构建、发布与维护

## 1. 运行

没有构建步骤。

```text
双击 index.html
```

或者用浏览器打开：

```text
file:///.../SnookerAI147/index.html
```

需要本机浏览器支持：

- ES5/ES2015 基本语法；
- Canvas 2D；
- WebGL；
- Web Audio；
- Blob Worker（AI 线程池）。

不支持 Worker 时，AI 自动回退同步 `decide()`，仍可玩，只是会卡一点。

## 2. 目录与资源

- 不要移动 `vendor/three.min.js`，`index.html` 按相对路径加载。
- `css/fonts.css` 是 base64 字体，体积较大，但保证 `file://` 可用。
- 不要引入外部字体/图片/音频 URL，离线会失效。
- 新增脚本必须同时改 `index.html` 和 `js/ai-pool.js`（如果 AI 需要）。
- `docs/` 只放文档，不参与运行。

## 3. 修改前备份

项目是 Git 仓库，但发布前仍建议做一次时间戳备份：

```powershell
$src = "C:\Users\zxw\Desktop\AI\SnookerAI147-20261017\SnookerAI147"
$dst = "C:\Users\zxw\Desktop\AI\SnookerAI147-20261017\_backup-YYYYMMDD-说明"
Copy-Item -Recurse $src $dst
```

备份放在项目父目录，不要放进仓库；否则容易被误提交。

## 4. Git 规范

- 提交信息用 `feat: / fix: / docs: / chore:`。
- 默认不自动 `push`，除非明确要求。
- 推送前先看：

```powershell
git status -sb
git log --oneline -5
git diff --check
```

- 不要把 `_backup-*`、临时测试脚本、浏览器缓存提交进去。
- 仓库地址：<https://github.com/EngineeringMechanicsB/SnookerAI147>

## 6. 已知限制

- 物理是离散帧 + CCD，极端高速/极薄球仍可能有模型误差。
- AI 受预算、候选网、切角上限限制，不保证几何上有一丝可能就必进。
- 8 球/9 球 AI 没有斯诺克式深度走位搜索。
- 程序化音频不可能完全复刻真实录音。
- 3D 场景是多灯阴影，低端 GPU 可能掉帧。
- 教学进度只存本地浏览器，清数据会丢。

## 7. 维护建议

- 改物理参数后，先跑自检 A，再看 AI 力度估计是否仍然匹配。
- 改 AI 搜索后，先跑自检 B/D，不要只看单局。
- 改 UI 后，先检查球台尺寸是否变化。
- 改 3D 后，先看俯视正交，再看轨道；不要在轨道视角调球位。
- 改音频后，单独听击球，不要被 BGM 干扰。
- 新增球员画像时，复制相近画像，只改 2~3 个权重，再用无头对局比较。

# Snooker · AI 147

纯前端斯诺克小游戏，双击 `index.html` 即可离线游玩。无构建步骤、无 npm 依赖，
three.js 已放在 `vendor/` 内。

## 功能

- 斯诺克规则：红球/彩球交替、清彩、复位黑球、犯规罚分、单杆计分
- 8-Ball / 9-Ball 模式：开放球台定组、黑八胜负、9 号球胜负、犯规自由球
- 真实物理：滑动/滚动摩擦、高低杆、侧旋（塞）、库边摩擦与踢球、球球 throw
- AI 对手：多档水平，决策与实机共用同一套 `stepWorld()` 物理，不做结果作弊；
  搜索走 Web Worker 线程池（默认 `hardwareConcurrency - 1`，上限 8）
- 后斯诺克（cue-block）：白球背后贴球或贴库时，低杆不是不能打，而是必须
  把球杆抬到足够角度让杆身越过障碍。几何上解出每个击点所需的最小仰角：
  贴死时打中心约需 45°，打最底部约需 56°；隔一个球径时中心约需 21°、
  底部约需 30°。出杆时自动把杆抬到 `max(玩家设置, 所需角度)`；
  玩家仍可在俯仰环上继续抬高。加塞盘标出最低仰角刻度，人类、AI 和
  瞄准预览共用同一份 `fitContact()`
- 教学模式：驾照式课程菜单，6 节课（直线进球、高杆、低杆、侧塞/库边、
  红彩计分规则、后斯诺克抬杆）。每课有摆球、目标圈、中英提示和真实物理判定，
  进度存 `localStorage`；可任选课程、重试或退出
- 2D / 3D 双视图：3D 为俯视正交相机，3D Orbit 可切透视轨道镜头
- 台球厅场景：双色墙面（护墙板 + 灰泥）、吧台/酒架/酒瓶、吊灯、挂画、
  挂钟、飞镖盘、球杆架、霓虹灯牌、窗与窗外光
- 瞄准辅助线：基于真实单杆模拟，支持关闭 / 仅母球 / 母球+首触 / 全部球
- 加塞与俯仰控制盘、力度条、存档/读档/导出、暂停、氛围光照预设
- 背景音乐、击球音效与环境声全部由 Web Audio 实时合成，无任何音频文件

## 音频

项目内**没有任何音频文件**，全部运行时合成：

- BGM：程序化爵士三重奏，8 小节循环（钢琴 comping / walking bass /
  ride + brush），奇数八分音符带 swing，和弦进行随机加花。
- 音效：皮头、球球碰撞、撞库、落袋，用噪声瞬态 + 带通滤波 + 指数包络合成。
- 环境：棕噪声街道底噪、带通人声底噪，随机插远处长喇叭、堵车短促连鸣、
  近距离双音喇叭、卡车气喇叭、警笛和低声交谈。
- 撞球音效仍做感知合批（55ms 窗口、175ms 上限、95ms 冷却）。

首次进入需要点击一次页面（浏览器自动播放策略）。声音开关与音量在顶部 HUD。

## 更新日志

### 2026-11-08

- 新增"后斯诺克"（cueing over a ball / cushion）机制：
  - 推翻上一版"下半球直接判死"的做法：低杆仍然能打，但白球背后的球或
    库边会强制球杆抬高；杆越低，只能打越靠上的击点；
  - 用杆身圆柱与挡球/库边的真实几何解出每个击点所需的最小仰角：
    贴球时中心击点约 45°、最底部约 56°，隔一个球径时中心约 21°、
    底部约 30°，与"抬杆后整颗球都能打"的直觉一致；
  - 出杆时自动把杆抬到 `max(玩家设置, 所需角度)`，操作不繁琐；
    玩家仍可在俯仰环上继续抬高，获得额外的高杆增量；
  - 被迫抬高的杆角只损失 `cos(仰角)` 的力量，不会偷偷改写玩家选的击点；
  - 60° 仍够不到的极点击点才被限制，并在加塞盘上画红色斜纹；
  - 加塞盘俯仰环上标出 `min X°`，击球文字显示实际 `cue X°`；
    玩家原本的加塞/俯仰设置不会被永久改写；
  - 2D/3D 球杆按实际仰角抬起，不再穿过挡球；
  - 人类出杆、AI 候选杆模拟、瞄准预览共用 `strike()` 里的
    `fitContact()`，自检"AI 声称 vs 实机复现"仍保持 100% 一致；
  - AI 防守估值新增 cue-block 项（按对手所需仰角计分），会主动把白球
    停到对手必须高杆击球的位置。
- 新增教学模式（GT 驾照式课程菜单）：
  - 6 节课：直线进球、高杆跟球、低杆缩杆、侧塞改变库边反弹、红彩计分规则、
    后斯诺克抬杆；
  - 每课有独立摆球、目标圈、中英说明和真实物理判定；多步课程（规则）自动推进；
  - 底部 `Tutorial` 按钮打开课程卡片，完成状态存 `localStorage`；
  - 课程中禁用 AI 与正常计分，退出后恢复座位设置并重开一局。
- 库边碰撞补上法向冲量的力矩项：法向冲量作用在球心上方约 0.27R 处，
  会改变球的平面内旋转。此前漏掉这一项，导致无塞中心球撞库后仍保留
  原来的滚动方向，沿新方向看像"自己带旋"。
- 球员对话频率降低：全局冷却 8s → 18s，气泡停留 6.8s → 5.5s；
  普通进球/失误的随机台词概率减半左右，催促冷却 28s → 60s，
  闲聊冷却 75s → 120s。

  多颗彩球同时复位时按分值从高到低处理。实机与 AI 模拟共用同一函数。

    贴着台底彩球做斯诺克不算消极。连续 3 杆提示 "Negative play"。

  - `opening` / `negativeStreak` 进入存档，读档后继续生效。

  限流。大球堆不再"哔哔哔"。
